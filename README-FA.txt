جیسون - پروژه اپلیکیشن اندروید
===============================

این فایل‌ها سورس پروژه اندروید هستند؛ APK آماده داخل ZIP نیست.

روش ساخت APK بدون کامپیوتر (با GitHub):
1) در GitHub یک حساب بساز و یک repository جدید به نام Jason ایجاد کن.
2) فایل ZIP را از حالت فشرده خارج کن.
3) همه فایل‌ها و پوشه‌های داخل JasonAndroid را در repository بارگذاری کن.
   حتماً پوشه .github هم بارگذاری شود.
4) وارد تب Actions شو و workflow با نام Build Jason APK را اجرا کن.
5) وقتی اجرا تمام شد، از صفحه اجرای workflow بخش Artifacts فایل Jason-debug-APK را دانلود کن.
6) ZIP دانلودشده را باز کن و app-debug.apk را روی گوشی نصب کن.
   ممکن است اندروید اجازه نصب از منبع ناشناس بخواهد.

ویژگی‌های نسخه 1:
- چت فارسی با پاسخ‌های ساده و از پیش‌تعریف‌شده
- دکمه میکروفون برای تبدیل گفتار فارسی به متن (وابسته به سرویس گفتار گوشی)
- خواندن پاسخ‌ها با Text-to-Speech (اگر صدای فارسی روی گوشی نصب باشد)

توجه: این نسخه هنوز هوش مصنوعی آنلاین نیست و پاسخ‌هایش محدود و از پیش‌تعریف‌شده‌اند.
برای ساخت APK امضاشده مخصوص انتشار عمومی، باید کلید امضا جداگانه تنظیم شود.
